# Tinker Tales 📚

A children's book creator that turns kids' stories into illustrated, printable books. Children narrate their story, AI generates matching illustrations, and the result is formatted into a book ready to print.

## Built With

- React.js
- AI image generation (compatible with multiple models — DALL·E, Stable Diffusion, etc.)
- PDF export for print

## Getting Started

```bash
git clone https://github.com/your-username/tinker-tales.git
cd tinker-tales
npm install
npm start
```
